API and configuration 
import { remarkChemfig } from
  'rehype-chemfig';

unified()
  .use(remarkParse)
  .use(remarkChemfig)
  .use(remarkRehype)
  .use(rehypeStringify);

Know the boundaries.

This is a native renderer for a documented subset of Chemfig, not a TeX engine. It draws what you write; it doesn’t infer hydrogens, validate valence, or optimize your layout.

Reaction schemes, charge macros, arbitrary TeX, TikZ styles, and submolecule aliases are not implemented. Unsupported input stays visible, with a diagnostic you can act on.
